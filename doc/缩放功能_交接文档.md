> 在进入调试模式（SW1 拨到 ON = 调节模式）的时候，新加入一个调试选项：**放大和缩小图片**。

> 例如从 100×100 变成 90×90 的大小。**如果变小就用黑色填充区域，如果放大的话，超出的部分直接切除不显示。**

- 默认 **100%**
- 以**屏幕中心**为基准，上下左右对称缩放
- 改缩放时会触发约 0.35 秒的图片重新装载，**用户已接受这个延迟**

## 二、项目背景（必读，避免踩坑）

**工程根目录**：`E:\project qianrushi\anlu\lab_ex5_i2s`
**TD 工程**：`src\td_project\HDMI1.4b_Transmitter_v1.0.al`（顶层 `top` 在 `src/user_source/hdl_source/top_tf_hdmi_audio.v`）

**时钟**：`sd_card_clk` 100MHz / `video_clk` 25MHz / `ext_mem_clk` 125MHz
**显示**：640×480@60Hz，SDRAM 双缓冲（BUF0=0，BUF1=307200）

**数据通路（图片）**：
```
sd_card_top → sd_card_bmp.v 内部：
                 bmp_read.v（扫描 BMP、输出像素流 src_bmp_wr/src_bmp_data）
                     ↓
                 img_scaler.v（★ 自适应缩放，本次功能也在这里扩展）
                     ↓
                 frame_fifo_write → SDRAM → 显示
```

**按键**（板卡丝印 → 引脚 → 本设计名字）：
- KEY_1 → A2 → `rst_n`（复位）
- KEY_2 → **B2** → **`key3`（减键）**
- KEY_3 → B1 → `key1`（短按切换/切图，工作模式长按快速连播）
- KEY_4 → C1 → **`key2`（加键）**

**拨码**：SW1=C8(调节模式) SW2=C7(自动轮播) SW3=C6(音乐开关) SW4=C5(字幕开关)

**已经踩过的坑（务必遵守）**：
1. `buf` 是 Verilog 保留字，不能当变量名（用 `sbuf`）
2. `output reg` 不能用 `assign` 驱动（HDL-8007），要用 `output wire`
3. **integer 参数不能做位选**（`PARAM[12:0]` 会报语法错），要先转 localparam
4. **数组绝对不能有"常量地址读"**（如 `sbuf[450]`）—— 会让 TD 放弃块 RAM，
   摊成触发器+巨型多路器，布局直接失败（PHY-8023）。要"顺手存进独立寄存器"。
5. TD 打开时会覆盖 `.al`，改工程文件前必须确认 `td.exe` 没运行
6. 视频流水线每插一级都必须用 `video_sync_delay` 把 hs/vs/de 延迟同样拍数
7. 改完代码给用户前，先跑一遍保留字/端口/括号的静态检查

## 三、已完成的部分

### ✅ `common/key_ctrl_fsm.v` —— 调节系统已加入「缩放」

- 新增调节项常量 `SEL_ZOOM = 2'd3`，调节项循环变成 4 项：
  **亮度 → 对比度 → 周期 → 缩放 → 亮度**
- 新增常量：`ZOOM_MIN=50`、`ZOOM_MAX=200`、`ZOOM_DEF=100`、`ZOOM_STEP=5`
- 新增寄存器 `reg [7:0] zoom_val;`，复位为 100
- `adj_up` 的 `SEL_ZOOM` 分支：`+5%`，到 200 回 50
- `adj_down` 的 `SEL_ZOOM` 分支：`-5%`，到 50 回 200
- 新增输出端口 `output wire [7:0] O_zoom_pct,` + `assign O_zoom_pct = zoom_val;`
- `O_adj_sel` 仍然是 2 位（0~3），循环判断改成 `(O_adj_sel == SEL_ZOOM) ? SEL_BRI : (O_adj_sel + 1)`

**操作方式**（已正确接好，不用改）：
- `key2`（KEY_4/C1）短按或长按连发 → 缩放 +5%
- `key3`（KEY_2/B2）短按或长按连发 → 缩放 -5%
- `key1`（KEY_3/B1）短按 → 切换调节项

### ✅ `SD/bmp_read.v` —— 已支持任意尺寸（前置改动）

- 去掉了"宽高必须等于 640×480"的检查，改成接受任意尺寸（限制 ≤2048，因为行缓存 2048 深）
- 新增输出：`O_img_w[15:0]`、`O_img_h[15:0]`（源图真实宽高）、
  `O_frame_start`（新图第一个像素：`bmp_data_wr_en && (bmp_len_cnt == pixel_offset)`）

### ✅ `SD/img_scaler.v` —— 已实现「自适应等比缩放到高度 480」

- 已插进 `sd_card_bmp.v`（在 `bmp_read` 和 `write_en/write_data` 之间）
- 算法：两个"比较式 DDA"（`w_acc < s_acc` 判据），全程只有加减法和比较，零乘除法
- 行缓存 `reg [23:0] lbuf [0:2047]`
- 已通过 Python 算法仿真验证：
  - 1920×1080 → 853×480（居中裁左右）
  - 800×600 → 640×480（满屏）
  - 1000×1000 → 480×480（左右各补 80 黑边）
  - 200×150 → 640×480（放大）

### ✅ `.al` 工程文件 —— 已注册 `img_scaler.v`（CompileOrder=60）

### 【第 2 步】把 `zoom_pct` 跨到 SD 时钟域

`key_ctrl_fsm` 在 `clk`(50MHz) 域，`img_scaler` 在 `sd_card_clk`(100MHz) 域。

**照抄 `top_tf_hdmi_audio.v` 里 `cfg_period_sec` 的做法**：

```verilog
// 1) 在 key_ctrl_fsm 例化处加：
.O_zoom_pct       (cfg_zoom_pct),

// 2) 声明 + 加一个 cfg_cdc 例化（紧挨着 u_cdc_period）：
wire [7:0] cfg_zoom_pct;
wire [7:0] cfg_zoom_pct_sd;

cfg_cdc #(
    .WIDTH (8)
) u_cdc_zoom (
    .I_clk_src (clk),
    .I_rst_src (rst_all),
    .I_data    (cfg_zoom_pct),
    .I_clk_dst (sd_card_clk),
    .I_rst_dst (rst_all),
    .O_data    (cfg_zoom_pct_sd)
);
```

### 【第 3 步】改 `SD/img_scaler.v`：加入缩放比例

**核心改动：把"缩放基准 480"换成一个变量 `H_dst = 480 × zoom / 100`。**

现在的逻辑（写死了 480）：
```
w_dst = I_w × 480 / I_h
纵向 DDA:  dy × I_h  vs  (sy+1) × 480
横向 DDA:  h_acc vs c_acc，步进量 480
```

改成：
```
H_dst = 480 × zoom / 100        ← 缩放后的图像高度
y0    = (480 - H_dst) / 2       ← 图像顶边（H_dst>480 时为负，表示上方被裁）
w_dst = I_w × H_dst / I_h
纵向 DDA:  (dy-y0) × I_h  vs  (sy+1) × H_dst
横向 DDA:  h_acc vs c_acc，步进量 H_dst
```

**纵向要新增"上下黑边"处理**（现在只处理了左右）：
- `dy < y0` → 输出黑行
- `dy >= y0 + H_dst` → 输出黑行
- 中间 → 走 DDA 决定用哪一行源数据

**`H_dst = zoom × 24 / 5`**（即 zoom×480/100）：用重复减法算，`tmp_num = zoom × 24`，然后减 5。

**注意 `H_dst` 可能 > 480**（zoom>100 时），此时 `y0` 为负。
建议用"带符号比较"或者把 `y0` 拆成 `y0_is_neg` + `y0_abs` 两个量处理。

### 【第 4 步】改 `SD/sd_card_bmp.v`：缩放值一变就重载当前图片

在 `sd_card_bmp.v` 里新增输入 `I_zoom_pct[7:0]`，并加一个"重载当前图"的触发：

```verilog
// 记住上一次的缩放值，检测变化
reg [7:0] zoom_d;
wire zoom_changed = (I_zoom_pct != zoom_d);
always @(posedge clk or posedge rst) begin
    if (rst) zoom_d <= 8'd100;
    else     zoom_d <= I_zoom_pct;
end

// 在"自动播放下一张"那个 else-if 链后面补一条"重载当前图"分支，
// 优先级放在自动播放之下、且要加"距离上次重载至少隔 400ms"的节流，
// 否则按键连发时会疯狂重载：
else if (scan_done && bmp_ready && display_valid && !load_busy
         && zoom_changed && reload_ok && (img_found_count != 3'd0)) begin
    load_idx        <= img_idx;                    // ★ 还是当前这张
    load_sector     <= sector_lut(img_idx);
    pending_buf_idx <= next_buf_lut(disp_buf_idx, display_valid);
    write_buf_idx   <= next_buf_lut(disp_buf_idx, display_valid);
    load_start_pulse<= 1'b1;
    load_busy       <= 1'b1;
    source_done_seen<= 1'b0;
    next_req_pending<= 1'b0;
    auto_sec_cnt    <= 16'd0;
end
```

节流：加一个 400ms 的计数器，重载后置位、计时到了才允许下次重载。
（`clk` 是 100MHz，400ms = 40_000_000 拍，27 位计数器）

同时把 `I_zoom_pct` 传给 `img_scaler` 的新端口 `.I_zoom(cfg_zoom_pct_sd)`。

### 【第 5 步】显示缩放百分比

**A. 数码管 `SD/seg_display.v`**
- 现在 `I_adj_sel` 是 2 位，`ADJUST` 模式位 3 显示 `1=亮度 2=对比度 3=周期`
- 加一个 `I_adj_sel == 2'd3` 的分支，位 3 显示 `4`（缩放）
- 位 2/位 1 显示缩放百分比：`I_value` 传进来是 50~200，**三位数装不下两位数码管** ✗
  → 建议显示"十位和个位"（即 100 显示 `10`，200 显示 `20`，50 显示 `05`），
    位 3 显示 `4` 表示"这是缩放项，读数是 ×10"

**B. OSD `video/osd_adjust.v`**
- `osd_value` 的选择表达式加上缩放项：
  ```verilog
  wire [15:0] osd_value = (vcfg_adj_sel == 2'd0) ? {11'd0, vcfg_brightness} :
                          (vcfg_adj_sel == 2'd1) ? {11'd0, vcfg_contrast}   :
                          (vcfg_adj_sel == 2'd2) ? {8'd0, cfg_period_sec_v} :
                                                   {8'd0, cfg_zoom_pct_v};
  ```
- 参数名要相应改（现在 `I_sel==2'd0/1/2` 分别显示"亮度/对比度/周期"），
  加 `2'd3` → 显示"缩放"
- `osd_adjust.v` 里显示 3 位数字：现在 `col 4` 是十位、`col 5` 是个位。
  缩放是三位数（50~200），要么改成只显示后两位（除以 10），要么扩一位。
