## 一、模块层次总览

```
top（顶层：src/user_source/hdl_source/top_tf_hdmi_audio.v）
│
├─① 时钟与复位（PLL，都是 TD IP）
│   ├── sys_pll ──────────── sd_card_clk 100M / ext_mem_clk 125M(含 180° 相移)
│   ├── video_pll ────────── video_clk 25M / hdmi_5x_clk 125M
│   └── PLL_HDMI_AUDIO ───── audio_mclk 12.288M（不再参与音频通路，仅维持 lock）
│
├─② 人机交互子系统（clk 50MHz）
│   ├── key_ctrl_fsm ─────── ★ 人机交互大脑：4 拨码 + 3 按键 → 全部配置参数
│   └── cfg_cdc × 5 ──────── ★ 配置参数跨时钟域（翻转握手）
│
├─③ SD 卡存储子系统（sd_card_clk 100MHz）★ 合规核心
│   ├── sd_card_top ──────── SD 卡控制器（SPI 模式，全工程唯一实例）
│   │   ├── spi_master           SPI 物理层收发
│   │   ├── sd_card_cmd          SD 命令层（CMD0/8/55/41/17/24）
│   │   └── sd_card_sec_read_write  扇区读写状态机
│   ├── sd_bus_arbiter ───── ★ 三级仲裁：音频告急 > 字幕 > 图片 > 音频补货
│   ├── 图片通道
│   │   ├── sd_card_bmp ──── ★ 图片调度：扫描/装载/轮播/双缓冲
│   │   │   ├── bmp_read ─── ★ 扫描 + 读任意尺寸 BMP
│   │   │   ├── img_scaler ─ ★ 自适应等比缩放（50%~200%，中心基准）
│   │   │   └── frame_fifo_write（写帧缓存，见 ④）
│   │   └── seg_display + seg_scan + seg_decoder   数码管显示
│   ├── wav_read ─────────── ★ 音乐通道（WAV 扫描 + 流式 PCM）
│   ├── txt_read ─────────── ★ 字幕通道（UTF-8 文本 → 字库索引）
│   └── rfifo_32_32_512 ──── 音频异步 FIFO（100M 写 / 25M 读，FWFT）
│
├─④ 帧缓存（ext_mem_clk 125MHz）
│   ├── frame_read_write ─── 帧缓存读写控制器（双缓冲 BUF0=0 / BUF1=307200）
│   │   ├── frame_fifo_read     读方向：SDRAM 突发读 + FIFO
│   │   └── frame_fifo_write    写方向：FIFO + SDRAM 突发写
│   └── sdram ────────────── 片内 8MB SDRAM 控制器（含加密 IP）
│
├─⑤ 视频流水线（video_clk 25MHz）—— ★ 每级都必须补 video_sync_delay
│   ├── video_timing_data ── 640×480@60Hz 时序（内含 color_bar 彩条底图）
│   ├── video_delay ──────── 读 SDRAM 数据对齐
│   ├── image_processor ──── ★ 亮度/对比度        （延迟 2 拍）
│   ├── fade_ctrl ────────── ★ 栅格化转场特效     （延迟 2 拍）
│   ├── osd_adjust ───────── ★ 左上角参数 OSD     （延迟 2 拍）
│   └── marquee_osd ──────── ★ 底部传送带字幕     （延迟 4 拍）
│
├─⑥ 音频通路
│   ├── audio_player ─────── ★ 48kHz 节拍 + underrun 补静音
│   └── audio_arc_calculate    ACR（CTS/N）计算
│
└─⑦ HDMI 输出
    ├── video_rgb_to_axis_640x480   RGB → AXIS 视频流
    ├── hdmi_1_4b_transmitter_core_wrapper   视频/音频打包（加密 IP）
    └── hdmi_phy_wrapper → lane_lvds_10_1 ×4   TMDS 串行化 → HDMI 引脚
```

★ = 本作品新增或改造的模块；其余为参考例程模块

## 三、四条改代码铁律（★ 违反必出 bug）

| # | 铁律 | 违反后果 |
|---|---|---|
| 1 | **视频流水线每插一级**，必须用 `video_sync_delay` 补同样拍数 | 画面左右偏移 / AXIS 撕裂 |
| 2 | 信号必须声明在**第一次使用之前** | 被当成 1 位隐式线网（HDL-7225），数据被截断 |
| 3 | 数组**不能有常量地址读**（如 `sbuf[0]`） | TD 放弃块 RAM → 布局失败（PHY-8023） |
| 4 | 配置跨时钟域：多比特用 `cfg_cdc`，单比特打 2 拍 | 亚稳态 / 参数错乱 |

## 四、流水线延迟速查（改代码前先看这张表）

```
vout_base（SDRAM 读出）
   → image_processor  +2 拍 → hs/vs/de 用 de_proc
   → fade_ctrl        +2 拍 → 用 de_fade
   → osd_adjust       +2 拍 → 用 de_osd
   → marquee_osd      +4 拍 → 用 de_marq
   → video_rgb_to_axis_640x480 → HDMI
```

**累计 10 拍**。任何一级改了内部级数，必须同步改它内部的 `video_sync_delay` 参数，
否则从那一级开始所有下游全部错位。
